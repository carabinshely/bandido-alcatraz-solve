# Игровой стол

Основа — выбранные пользователем макеты этого чата; оформление утверждено
до реализации. ENERGY 2 / RHYTHM 2 / MOTION 1.

- Бумага `#f7efd9`, карточка `#fffaf0`, коврик `#a55731`, акцент `#983b18`:
  тёплые материалы настольной игры, один цвет для выбора и основных действий.
- Golos Text для русского текста, Unbounded для заголовков: читаемые объяснения
  и характерный плотный заголовок согласованного макета.
- Настоящая геометрия сохранённой позиции вместо декоративной иллюстрации:
  поле объясняет выбор и соответствует данным движка.
- Тень только у физического игрового поля, кармана и карт руки: отделяет
  игровые предметы от справочного текста.
- Семь карточек игровых задач, полный список алгоритмов и последовательность
  этапов: разные структуры одного содержания, выбранные пользователем.
- Блоки объяснения, поле и таблицы имеют разный ритм по задаче чтения.
  Точный алгоритм раскрывается отдельно, чтобы не перегружать игрока.
- Пространство 20px на телефоне и 42px на рабочем столе сохраняет читаемую
  ширину. Коврик резервирует место для вынесенной карточки подписи.
- Автоматического движения нет; изменения происходят по нажатию. Светлая,
  тёмная и системная темы доступны через один переключатель.
