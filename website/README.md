# Bandido: Alcatraz — игровой гид на русском и английском

Статический сайт в согласованном стиле «Игровой стол»: три вида каталога,
15 политик, семь групп игровых задач, правила, результаты и разбор позиции.
Каждая из 27 страниц имеет английскую версию в `en/`. Переключатель языка
открывает ту же страницу с теми же вкладкой и якорем.

## Запуск в Windows

Из корня репозитория:

```powershell
py -3.14 website/build.py
py -3.14 -m http.server 8765 --bind 127.0.0.1 --directory website/dist
```

Открыть http://127.0.0.1:8765/ . Для остановки сервера — Ctrl+C.
Основная разработка и CI используют Python 3.14. Сборка и сайт не требуют внешних библиотек,
интернета, npm или API. Шрифты встроены локально.

## Структура

- `content.json` — единый набор описаний, групп и этапов.
- `templates/` — общий каркас и справочные страницы.
- `locales/en.json` — английские переводы всех текстов страниц.
- `localize.py` — перевод статических документов с проверкой полноты.
- `assets/` — стили, браузерные взаимодействия, локальные шрифты.
- `inputs/` — сохранённая публичная позиция и исходный пакет проверки A/B.
- `replay.py` — пересчёт выбора 15 политик на одной позиции, без добора и партий.
- `build.py` — генерация HTML, JSON для агента и пакетов воспроизведения.
- `dist/` — готовый сайт; генерируется локально, исключён из Git.
- `check.cjs` — проверка в установленном Chrome через встроенные модули Node.
- `.qa/` — локальные скриншоты и протоколы; исключены из Git.

Три вкладки меняют организацию каталога. Страницы стратегий общие для всех
видов, имеют обычные адреса `strategies/v4.html` и сохраняют контекст возврата.
Вкладки работают с клавиатуры; выбор запоминается, если хранилище браузера
доступно. Все ссылки относительные и допускают префикс проекта GitHub Pages.

## Проверки

```powershell
.venv/Scripts/python.exe -m pytest tests/test_website.py -q
node website/check.cjs
```

Для браузерной проверки нужен существующий Google Chrome в стандартном
Windows-пути или переменная `CHROME_PATH`. Проверка поднимает свой временный
HTTP-сервер с префиксом `/project/` и завершает собственный процесс Chrome.
Первый тест собирает сайт; остальные проверяют источники и запускают оба
скачиваемых ZIP-пакета вне репозитория.

## Границы данных

Каждая политика показана на одной настоящей позиции (seed 1000263, решение 8).
Выбор заново рассчитан с RNG=0; это не исходный исторический ход и не новая
оценка частоты побед. Для V5 эта позиция не активирует защиту выхода: EXIT уже
виден. Результаты по текущим правилам доступны для V4-250 и CatalogSupport;
исторические эксперименты обозначены отдельно.

## Публикация

GitHub Pages использует `.github/workflows/pages.yml`: после изменений в `main`
собирает обе языковые версии, запускает тесты сайта и публикует `dist/`.
Есть ручной запуск workflow. Сборка и развёртывание используют существующий
self-hosted Linux runner с меткой `bandido-alcatraz-tests`; GitHub-hosted fallback нет.

Русская главная: https://carabinshely.github.io/bandido-alcatraz-solve/

Английская: https://carabinshely.github.io/bandido-alcatraz-solve/en/index.html

Изменение русского текста без перевода останавливает сборку с сообщением о
пропущенной строке. Исходники, параметры, числовые данные и воспроизведение
общие; переводы не создают отдельные расчёты. Встроенные ссылки на исходные
научные документы сохраняют оригинальный язык этих документов.
