# Candidate deck image sources

Research date: 2026-09-21.

## Best current lead: Zatrolené hry

Gallery:
https://www.zatrolene-hry.cz/spolecenska-hra/bandido-alcatraz-20210/obrazky/?sort=date

The indexed gallery explicitly lists four card-photo groups:

1. equipment cards (ropes and raincoats), EXIT card, and card back;
2. a selection of tunnel cards;
3. water cards;
4. both sides of the double-sided start tile (easy 5 tunnels, standard 6 tunnels).

This is currently the strongest source for reconstructing card geometry visually. It is not yet evidence that all 68 ordinary cards or their multiplicities are shown.

## BoardGameGeek

Game:
https://boardgamegeek.com/boardgame/460438

The game has a public image gallery (14 images as of the research date). One publisher image titled "Box and Cards" is available at:
https://boardgamegeek.com/image/9445809/bandido-alcatraz-10th-anniversary-edition

Useful for geometry examples, but not currently sufficient for complete deck multiplicities.

## Publisher / regional publisher

Fractal Juegos:
https://fractaljuegos.com/en/juegos/bandido-alcatraz/

Confirms:
- 68 ordinary cards;
- 4 water cards;
- 8 rope cards;
- 12 raincoat cards;
- 1 start tile;
- 1 EXIT card.

This is authoritative for aggregate counts, not detailed geometry frequencies.

## Original Bandido fallback/reference only

Board Game Arena documents the original Bandido distribution:
https://en.doc.boardgamearena.com/Gamehelpbandido

It states:
- 69 tunnel tiles;
- 2 copies each of 24 basic configurations;
- 3 copies each of 7 end-tunnel configurations.

It also links to a tile-list image.

Important: Bandido Alcatraz reimplements Bandido, but we must not assume the Alcatraz 68-card geometry distribution is identical. Use the original distribution only as a comparison/check once Alcatraz images are transcribed.

## Next verification task

Do not create deck-v1 until multiplicities are independently verified.
