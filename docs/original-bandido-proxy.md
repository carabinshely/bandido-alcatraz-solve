# Original Bandido proxy sources

These sources are used only to build a realistic geometry proxy while the exact
Bandido: Alcatraz card multiset remains incomplete.

## Helvetiq Bandido COVID-19 print-and-play

Official PDF:

https://helvetiq.com/media/hexaattachment/products/attachments/Bandido_Covid-19_EN.pdf

The PDF is especially useful because the cards are supplied as flat,
print-ready artwork rather than perspective photographs.

Board Game Arena documents the COVID-19 distribution as:

- 1 starting tile with 5 exits;
- 1 starting tile with 6 exits;
- 32 tunnel tiles;
- 22 basic configurations, one copy each;
- 4 end configurations, two copies each;
- 2 end configurations, one copy each.

Board Game Arena source:

https://en.doc.boardgamearena.com/Gamehelpbandido

The standard original Bandido distribution is documented as:

- 69 tunnel tiles;
- 24 basic configurations, two copies each;
- 7 end configurations, three copies each.

Therefore the COVID print-and-play exposes 22 of the 24 standard basic
configuration families and 6 of the 7 standard end configuration families.
That makes it a strong geometry proxy, but not an Alcatraz deck definition.

## Provenance rule

Anything transcribed from this PDF must carry:

- `confidence = proxy`;
- the PDF source URL;
- PDF page and card slot;
- no claim that its multiplicity applies to Alcatraz.

Alcatraz observations always remain separate from this proxy dataset.
