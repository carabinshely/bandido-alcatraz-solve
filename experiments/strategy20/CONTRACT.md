# Strategy20 candidate contract (source only)

This is a prospective, unissued strategy variant. It has not played a game and has no win-rate claim. The six paired19 seeds, 1000417–1000422, are spent development data and cannot be used to assess this variant as fresh evidence.

The candidate accepts the same exact detached public observation, own hand, photographed catalog, START and EXIT pins as `QuotaReserveClosurePolicy`, and additionally verifies the easy START has five open tunnels and the live board placement counter matches its history. It never reads the hidden draw pile. Its control is canonical V4 with setup weight 250. For each legal action it computes the canonical V4 score. It previews each placement without a draw and marks it risky if the successor has fewer than three open tunnels and is not an immediate win. Collection is never risky. When at least one legal action is not risky, it removes risky actions and selects the maximum V4 score from the remainder, using one canonical RNG choice among tied roots. When every legal action is risky, it falls back to the unchanged V4 maximum tier. Empty legal roots yield no move.

The independent reference uses a separately written tier calculation with the same public input and canonical geometry/scoring functions. Both entry paths require an immutable catalog tuple, a non-equipment EXIT, the correct START identity, a START with exactly five open tunnels, an integer, history-consistent board placement counter, and a Random-compatible RNG. A returned RNG choice outside the final tier is rejected. The audit records every legal root and score, projected open-tunnel count, risk classification, safe/final tiers, chosen root, public-input hashes, RNG hashes and actual physical call counts. Candidate and reference must agree on the exact audit, choice and physical costs before scientific admission.

The floor of three was fixed after inspecting paired19 loss traces with terminal open counts of one and two. That observation is hypothesis generation, not threshold validation. Any game evaluation requires a separately frozen runner, fresh global seeds, prospective resource bounds, independent reviews and a root execution GO. This source contract grants none of those.
